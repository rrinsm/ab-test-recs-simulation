# A/B-тест блока рекомендаций в телеком-приложении (симуляция)

Учебный проект: полный цикл анализа A/B-эксперимента для нового блока рекомендаций в мобильном приложении оператора. Данные **синтетические** (200 000 пользователей, истинные эффекты заданы в генераторе), чтобы можно было проверить, что методы находят известный эффект и не находят несуществующий.

## Что делает скрипт `ab_recs_experiment.py`
1. Генерирует пользователей: платформа, стаж, сессии до теста, случайное разбиение 50/50.
2. Считает метрики по группам SQL-запросом (SQLite).
3. Проверяет корректность сплита (SRM, χ²).
4. Считает необходимый размер выборки для MDE 3% и 5%.
5. Тестирует CTR (z-тест для долей, доверительный интервал).
6. Тестирует сессии на пользователя: Welch t-test и CUPED (ковариата: сессии до теста).
7. Строит bootstrap-интервал для CUPED-метрики.
8. Проверяет guardrail-метрику (обращения в поддержку).
9. Применяет поправку Холма на множественные сравнения.
10. Прогоняет 500 A/A-тестов, чтобы проверить долю ложных срабатываний.

## Результаты запуска (seed = 42)
| Проверка | Результат |
|---|---|
| SRM (контроль / тест) | 100 263 / 99 737, p = 0.24, перекоса нет |
| Базовый CTR | 25.7% |
| Нужно пользователей на группу (MDE 3% / 5%) | 50 792 / 18 399 |
| CTR: прирост | +3.15 п.п. (+12.2% отн.), 95% ДИ [2.76; 3.54] п.п., p < 0.001 |
| Сессии: Welch t-test | +1.2%, p = 0.0004 |
| Сессии: CUPED | корреляция с pre-периодом 0.86, дисперсия снижена на 74%, p ≈ 1e-12 |
| Bootstrap ДИ (CUPED, разница средних) | [0.060; 0.106] сессий |
| Guardrail: обращения в поддержку | p = 0.42 (изменений нет) |
| A/A-тест, 500 прогонов | доля ложных срабатываний 5.6% при α = 5% |

## Запуск
```
pip install numpy pandas scipy
python ab_recs_experiment.py
```
Результаты сохраняются в `results.json`.

## Ограничения
Данные искусственные, поэтому проект показывает владение методологией, а не выводы о реальном продукте.
